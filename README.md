# Logistics Data Analysis

A Python-based logistics and supply chain analytics project covering data profiling, KPI analysis, prediction, clustering, and route optimization.

## Project Structure
- `data/` — raw, processed, and external datasets
- `notebooks/` — analysis and modeling notebooks
- `src/` — reusable Python modules for cleaning, features, KPIs, models, and optimization
- `outputs/` — generated figures, models, and reports

## Getting Started
Install dependencies with:

```bash
pip install -r requirements.txt
```

Then run the notebooks in order from `01_data_profiling.ipynb` through `05_route_optimization.ipynb`.
